# Group 6: Layout & Resize (Stories 23-26)

Narration scripts for shaping your workspace: layout mode, resizing, equalize / swap / fullscreen, and directional navigation.

**Total duration:** ~2 min 50s

---

## Story 23: Layout Mode (Ctrl+L) (45s)

### Scene Breakdown

| Time | Visual | Narration |
|------|--------|-----------|
| 0:00 | Title card: "Layout Mode" | "Ctrl+L is where you shape your workspace -- resize, equalize, swap, and fullscreen." |
| 0:04 | Type `rysh`, `Ctrl+P n` twice | "Start rysh and split into a few columns so we have something to rearrange." |
| 0:14 | Press `Ctrl+L`, footer shows bindings | "Press Ctrl+L to enter layout mode. The footer lists every shaping key." |
| 0:20 | Press `Right` twice, pane widens | "Arrow keys resize the active pane -- Right and Left for width, Up and Down for height." |
| 0:28 | Press `=`, then `m` fullscreen | "Press equals to balance the widths back out, and m to fullscreen the active pane." |
| 0:36 | Press `m` again, then Escape | "Press m again to restore, then Escape to leave layout mode. Resize, equalize, swap, fullscreen -- all under Ctrl+L." |

### Key Moments to Annotate
- [0:14] Key badge: `Ctrl+L`; highlight footer binding list
- [0:20] Key badges: arrow keys
- [0:28] Key badges: `=` (equalize), `m` (fullscreen)

## Story 24: Resizing Panes (40s)

### Scene Breakdown

| Time | Visual | Narration |
|------|--------|-----------|
| 0:00 | Title card: "Resizing Panes" | "Give the important pane more room -- arrow keys in layout mode flex the space." |

| 0:14 | Press `Ctrl+L` | "Press Ctrl+L. Now the arrow keys resize the active pane." |

| 0:27 | `Up`, `Up`, `Down` | "Up and Down adjust height within the column. It's all flex-based, so the layout always stays proportional." |
| 0:35 | Press Escape, hold | "Escape when it looks right. Arrow keys -- the simplest way to tune every pane's size." |

### Key Moments to Annotate

- [0:27] Key badges: `Up` / `Down`; callout "height via flex"

## Story 25: Equalize, Swap & Fullscreen (45s)

### Scene Breakdown

| Time | Visual | Narration |
|------|--------|-----------|
| 0:00 | Title card: "Equalize, Swap & Fullscreen" | "Three quick moves to reset chaos: equalize, swap lanes, and go fullscreen." |
| 0:04 | Type `rysh`, split to columns, `Ctrl+L`, `Right` x2 | "Start rysh, split into columns, then grow one pane wide so we've got an uneven layout to fix." |
| 0:16 | Press `=` (or `h`), widths balance | "Still in layout mode, press h or equals to equalize all the widths -- instantly balanced columns." |
| 0:23 | Press `v`, heights balance | "Press v to equalize heights the same way for stacked rows." |
| 0:30 | Press `s`, lanes swap | "Press s to swap lane positions and reorder your columns." |
| 0:37 | Press `m` twice, then Escape | "And m fullscreens the active pane -- same as Alt+P f from normal mode. Press it again to restore, Escape to finish." |

### Key Moments to Annotate

- [0:23] Key badge: `v` (equalize heights)
- [0:30] Key badge: `s` (swap lanes)
