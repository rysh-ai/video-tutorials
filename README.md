# Rysh Video Tutorials

50 short video tutorials explaining every major feature of the Rysh project, organized into 13 groups.

## Directory Structure

```
video-tutorials/
├── README.md                          # This file -- overview and index
├── video-stories.md                   # Master story document (all 50 stories)
├── production-guide.md                # Recording setup, tools, visual style
├── scripts/                           # Per-group narration scripts
│   ├── 01-getting-started.md          # Stories 1-4
│   ├── 02-multiplexer-basics.md       # Stories 5-10
│   ├── 03-input-modes.md              # Stories 11-14
│   ├── 04-interactive-terminal.md     # Stories 15-17
│   ├── 05-ai-agentic-features.md      # Stories 18-23
│   ├── 06-autonomous-agents.md        # Stories 24-28
│   ├── 07-humanoids.md                # Stories 29-32
│   ├── 08-collaboration-sharing.md    # Stories 33-37
│   ├── 09-pipelines-events.md         # Stories 38-40
│   ├── 10-web-terminal.md             # Stories 41-43
│   ├── 11-mobile-app.md               # Stories 44-45
│   ├── 12-chrome-extension.md         # Stories 46-47
│   └── 13-server-billing.md           # Stories 48-50

│   └── narration-guide.md             # Narration tips and tone guide

    └── diagrams.md                    # ASCII diagrams for on-screen use
```

## Quick Start

1. Read `video-stories.md` for the full story breakdown.
2. Read `production-guide.md` for recording setup.
3. Pick a group from `scripts/` and follow the narration script.
4. Use `checklists/recording-checklist.md` to prepare your environment.
5. Place diagrams and screenshots in `assets/`.
