### Why

audio). The masters were therefore **never committed**. They were rendered on a checkout at
`/Users/halilagin/root/github/agentic-zellij`, which does not exist on this machine:

```sh
ls -d /Users/halilagin/root/github/agentic-zellij   # → No such file or directory
```

That path was still hardcoded in three render/compose scripts until this branch fixed it
(see §5). Ungitignored, unpushed, on a deleted checkout — the masters are unrecoverable
from this repo.

## 4. A counting trap worth recording

The glob `*ad*` over-matches on ordinary words. `ls tapes/tape/*ad*.tape` returns **13**
files, but three are false positives:

- `story-049-re`**`ad`**`ing-searching-files.tape`
- `story-058-re`**`ad`**`ing-background-output-killing.tape`
- `story-086-lo`**`ad`**`ing-running-pipelines.tape`

The same trap inflates the `.say` and `.mp3` counts — `ls tapes/say/*ad*.mp3` appears to
show three ad voiceovers that are really "reading"/"loading" story files. **The true ad
`.mp3` count is 0.** Always match `story-ad*`, not `*ad*`. Any future audit that reports 13
ad tapes or non-zero ad mp3 has hit this bug.

## 5. Render pipeline: what this branch fixed

Three scripts hardcoded the dead `agentic-zellij` path. All now derive their roots from the
script's own location, following the `tapes/render-ad07.sh:25` idiom:

| File | Before | After |
|---|---|---|
| `demos/secretnat/render-ad11.sh:7-9` | `REPO=/Users/halilagin/root/github/agentic-zellij` | `PROXYDIR` from `BASH_SOURCE`; `VT="$(cd "$PROXYDIR/../.." && pwd)"` |
| `demos/secretnat/compose-ad11.sh:6` | `T=…/agentic-zellij/video-tutorials/tapes` | `T="$(cd "$(dirname "${BASH_SOURCE[0]}")/../../tapes" && pwd)"` |
| `demos/secretnat/compose-teaser.sh:5` | same | same |

`render-ad11.sh` derives the **video-tutorials root** (`VT`) rather than the repo root.
Reconstructing `$REPO/video-tutorials/...` — as `render-ad07.sh` does — breaks inside a
worktree, where the checkout is named `video-tutorials-<branch>`, not `video-tutorials`.
`REPO` was used only to rebuild those two paths, so dropping it changes no behaviour and
makes the script worktree-safe. Verified by running the derivation from `cwd=/`, `$HOME`,
and `/usr` — identical, correct results each time.

Unchanged, verified still present after the edit: the `.rysh/secrets` hygiene abort
(`:30`), the `ANTHROPIC_API_KEY` guard (`:35`), and the deleted-inode fix — `wire.log` is
cleared at line 22 and the proxy starts at line 25, so the proxy's file handle points at
the live file the on-camera `grep` reads.

Three tracked rysh **session-state JSONs** also carried the dead path
(`tapes/render-sandbox-ad04/{owner,team}/.rysh/sessions/*.json`,
`demos/guest-scout/.rysh/sessions/guest-scout.json`). These are machine-local state, not
scripts — they record a `path`, `config_file`, and `rysh_dir`, plus a stale `pid` from
2026-07-17 — so they cannot derive anything. Their prefix was repointed to
`/Users/halilagin/github/rysh`. They are regenerated by `rysh` on the next render.

`grep -rn 'agentic-zellij' video-tutorials` now returns nothing.

## 6. What re-rendering needs — gates per asset

The commands used to build §2:

```sh
for n in 01 02 03 04 05 06 07 08 09 10 11; do
  printf 'ad%s tape=%s say=%s srt=%s mp4=%s\n' "$n" \
    "$(ls tapes/tape/*ad$n*.tape 2>/dev/null | wc -l)" \
    "$(ls tapes/say/story-ad$n*.say 2>/dev/null | wc -l)" \
    "$(ls tapes/out/story-ad$n*.srt 2>/dev/null | wc -l)" \
    "$(find . -name "story-ad$n*.mp4" 2>/dev/null | wc -l)"; done
```

### One structural prerequisite

`*.mp4`/`*.gif` are gitignored. **Re-rendering into `tapes/out/` repeats exactly the history
documented above** — masters that exist on one machine and vanish with it. Decide where
masters live (git LFS, or a `packages.rysh.ai` bucket) *before* the next render, not after.
