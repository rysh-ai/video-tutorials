# Acme Billing API (mock) — generated MCP server

Generated by Rysh Forge from a openapi spec (5 operations).

## Run

stdio (default):

    go run .

Streamable HTTP:

    go run . --http :8080
    # MCP endpoint: POST http://localhost:8080/mcp

## Configuration (environment)

- API_KEY    — credential injected per the API's auth scheme
- API_USER / API_PASS — for HTTP basic auth
- BASE_URL   — override the upstream base URL (default "http://localhost:8099")

Register with an MCP client, e.g. Claude Code:

    claude mcp add --transport http acme-billing-api-mock http://localhost:8080/mcp
